# ai-ml-projects

A collection of smaller AI/ML learning projects and experiments.

## Featured project

**[llm-eval-bench](https://github.com/djdelacruz2024/llm-eval-bench)**: an open-source, multi-model LLM benchmarking and evaluation framework. It uses an LLM-as-judge to score accuracy, faithfulness/hallucination, and empathy, tracks latency and cost, runs a no-RAG robustness suite, and includes a results dashboard. It started in this repo and now lives in its own repository.
